# Gateway

Gateway 是一个面向商户的生产级开源稳定币支付系统，目标覆盖充值、出款、双分录账本、链上索引、商户回调、对账与异常恢复。

首个稳定版本聚焦 `USDT-TRC20`，之后通过链适配接口扩展 EVM，并以独立扩展提供 x402 支持。

## 当前状态

项目处于早期建设阶段，尚未经过安全审计，不能直接用于承载真实资金。

已开始实现：

- 生产方案与里程碑
- HTTP 服务基础骨架
- 双分录账本领域约束
- PostgreSQL 核心账本表结构

## 本地运行

要求 Go 1.23 或更高版本。

```bash
go run ./cmd/gateway-api
```

默认监听 `127.0.0.1:8080`：

```bash
curl http://127.0.0.1:8080/healthz
```

可用环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `GATEWAY_HTTP_ADDR` | `127.0.0.1:8080` | HTTP 监听地址 |
| `GATEWAY_READ_HEADER_TIMEOUT` | `5s` | 请求头读取超时 |
| `GATEWAY_SHUTDOWN_TIMEOUT` | `10s` | 优雅退出超时 |

## 安全边界

- 业务服务不得保存或记录明文私钥。
- 生产签名必须通过独立远程签名服务、HSM 或 MPC 适配器完成。
- 主网能力必须显式启用，并通过发布检查清单。
- 地址筛查、KYC、AML 与牌照责任由部署运营方根据所在司法辖区落实。
